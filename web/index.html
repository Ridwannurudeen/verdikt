How it works

A dispute, decided by an AI jury — autonomously.

A consumer opens a case with evidence. The court convenes a panel of Somnia validator agents that each run the same inference and must converge byte-identically. The verdict is delivered back programmatically.

FAQ

Questions.

Why an AI jury instead of a human one?

Human arbitration (juror panels) is slow and expensive; a single off-chain bot can't be trusted. Somnia's validators each run the inference and reach consensus on a byte-identical result — making AI judgment trust-minimized, fast, and on-chain. Verdikt measures 92% agreement with human verdicts.

What stops a party from gaming the prompt?

Evidence is sanitized (angle brackets stripped) and wrapped in a fenced block the system prompt marks as untrusted, so a party can't break out and inject instructions. We proved it live: a panel ignored an embedded "output PAYEE" and ruled on the facts.

What if the evidence is genuinely unclear?

The panel can answer UNDECIDABLE and refund the depositor, rather than guess. Trusted on-chain attestors can also post verified facts the court weighs above the parties' claims.

Can other protocols build on it?

Yes — VerdiktCourt is a reusable primitive. Inherit VerdiktConsumerBase and a protocol integrates the jury in a few lines; six consumers already share one court, and a staked marketplace lets operators run competing courts.
