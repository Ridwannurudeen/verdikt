# AI Usage

Verdikt used AI assistance during development for engineering support only. The project design, product direction, hackathon submission decisions, and final approval remain with the project owner.

## Tools Used

- OpenAI Codex / ChatGPT: codebase audit, security review, Solidity hardening, frontend/backend bug fixing, test expansion, documentation updates, and verification planning.

## Scope of Assistance

- Reviewed smart contracts for settlement, appeal, escrow, insurance, token transfer, registry, and reputation risks.
- Implemented pull-payment settlement patterns, refund handling, appeal deadline snapshots, registry validation, ERC-20 transfer compatibility checks, and insurance pool accounting fixes.
- Added and updated Foundry tests for security-critical behavior and edge cases.
- Reviewed and hardened keeper, indexer, deployment, and static frontend flows.
- Updated project documentation to reflect the audited state and remaining deployment steps.

## Human Review

All generated or edited code is intended to be reviewed, tested, and approved by the project owner before deployment or hackathon submission.
